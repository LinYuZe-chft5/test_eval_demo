# 学科诊断产品设计与题库建设总规范

**版本**：V1.0（定稿）
**适用产品**：《7天极简学科诊断MVP付费验证计划》——河北省初中数学（冀教版2024）+ 高三数学（人教A版）学科能力诊断服务
**文档结构**：产品定义层 → 测量设计层 → 题库层 → 施测层 → 报告生成层 → 验证闭环层 → 数据架构 → 二期预留 → 商业化与扩科路线（附录A命题提示词 / 附录B决策记录 / 附录C教材目录）

---

## 文档说明与核心原则

本规范由六轮产品设计讨论与两份外部算法架构文件（《精准诊断测评元架构及PRD V2.0》《精准诊断测评系统PRD V2.1》）的组件级融合沉淀而成，是全产品线的唯一上游文档。后续命题、题库建设、H5开发、报告生成的所有参数，必须能从本规范追溯来源，禁止下游独立发挥。

**五条贯穿全程的总原则**：

1. **单向推导链**：定位卡 → 蓝图参数 → 命题规格 → 施测方案 → 报告模板。换SKU = 换定位卡，下游参数按推导规则自动生成。
2. **一卷一定位**：一份试卷只服务一个诊断定位，严禁"一卷多用"，不同定位的数据不可混用。
3. **决策权分配**：学什么顺序（路径定序）由确定性算法决定；用什么方法（干预手段）由人工审核的预制件决定；怎么表达（叙述措辞）由AI决定；能不能发出去（质量门禁）由人决定。
4. **规则先行，数据校准**：所有学术级模型（IRT、贝叶斯）让位于工程级规则引擎先跑通；所有初始参数（权重、阈值）标记"待校准"，前200单真实数据回流后统一反向校准。
5. **诊断与验证双轮**：诊断输出的是"概率性结论"，必须经"干预→等值后测"的因果验证闭环锁定或推翻，系统才能持续收敛到真实学习障碍。

# 第一部分 产品定义层：诊断定位体系

## 1.1 为什么定位层是总开关

诊断目的决定测量设计：内容范围、难度基准、Q矩阵结构、结论框架、报告话术全部由诊断定位推导。同一知识点，在衔接诊断和升学诊断中的考法、难度、结论形式完全不同。定位不清，下游一切参数失去锚点。

## 1.2 SKU枚举：学业生命周期轴

SKU按学生必然经历的时间窗口排列，首尾相接构成复购链：

| 序号 | SKU名称 | 学段/施测窗口 | 诊断目标 | 家长核心焦虑 | 商业角色 |
|---|---|---|---|---|---|
| S0 | 15分钟能力快筛（二期） | 全年 | ①摸底（粗） | "先免费看看孩子什么水平" | 引流款（CAT自适应，转付费） |
| S1 | 小升初衔接适应期诊断 | 六升七暑假~七上开学8周 | ④衔接+①摸底 | "孩子跟得上初中吗" | 引流款，走量 |
| S2 | 七上期中适应诊断 | 七上10-11月 | ③错因+①摸底 | "开学两个月问题出在哪" | 期中考后转化 |
| S3 | 七升八难度跃升衔接诊断 | 七升八暑假 | ④衔接+⑤专题 | "初二两极分化是真的吗" | 暑假续报 |
| S4 | 八年级专题突破诊断 | 八年级全年滚动 | ⑤专题 | "全等证明/一次函数学不会" | 按痛点模块拆子SKU |
| S5 | 八升九中考启动诊断 | 八升九暑假 | ①摸底+④衔接 | "这个暑假该补什么" | 中考线入口，利润款 |
| S6 | 中考一轮基础诊断 | 九年级9-11月 | ①摸底+③错因 | "基础还有哪些窟窿" | 一轮复习期 |
| S7 | 中考二轮专题诊断 | 九年级12月-次年3月 | ⑤专题+②分级 | "压轴题能不能拿分" | 二轮冲刺期 |
| S8 | 中考全真模拟诊断 | 九年级4-5月 | ②分级+升学预测 | "能上什么高中" | 考前峰值，溢价款 |
| S9-S11 | 高三一轮模块/二轮专题/模拟诊断 | 高三对应窗口 | 同S6-S8逻辑 | 同上（高考版） | 高客单价产品线 |

**设计意图**：衔接款（S1/S3/S5）单价低、决策门槛低，用于获客；同步与专题款（S2/S4/S6/S7）天然带"诊断→干预→复测"续费钩子；模拟款（S8/S11）对应考前付费意愿峰值，且是常模百分位需求最刚性的产品。

**MVP首发范围**：S1（小升初衔接）+ S6（中考一轮诊断），分别验证衔接逻辑与升学逻辑两条核心假设。

## 1.3 诊断定位卡V2（10字段，每SKU一张）

字段准入标准：每个字段必须驱动下游一个具体参数。

| 字段 | 填写规范 | 驱动下游 |
|---|---|---|
| ① 诊断定位名称 | 一句话概括诊断场景 | 营销话术+报告标题 |
| ② 适用对象 | 年级+学期+学情特征 | 蓝图教材范围锚定 |
| ③ 诊断目标 | 5类选1-2个：①知识摸底 ②能力分级 ③错因扫描 ④升学衔接 ⑤专题突破 | 元数据字段开关+结论产出类型 |
| ④ 难度基准 | 目标群体预期均分（100分制） | 蓝图平均难度P的锚 |
| ⑤ 重点模块权重 | 3-4个模块+分值占比（衔接类必须含"前置知识"配额） | 双向细目表配额约束 |
| ⑥ 报告解读侧重 | 家长最焦虑的3个问题 | 报告模板选择+话术基调 |
| ⑦ 与升学关联度 | 低/中/高 | 建议深度+目标设定方式 |
| ⑧ 前置知识下探 | 否 / 是（下探至具体知识点） | Q矩阵层数：下探→双层Q矩阵+依赖链标注 |
| ⑨ 参照系类型 | 标准参照 / 常模参照（注明常模群体） | 报告结论形式（掌握度清单 vs 百分位） |
| ⑩ 复测周期与钩子 | 建议复测间隔+复测指向的下一个SKU | 报告末尾续报设计+验证闭环触发 |

**示例：小升初衔接适应期诊断（S1）**

| 字段 | 填写值 |
|---|---|
| ①名称 | 小升初衔接适应期诊断 |
| ②对象 | 七年级新生/开学4-8周/小学升初中过渡阶段 |
| ③目标 | ④升学衔接+①知识摸底 |
| ④难度基准 | 预期均分70-78（故意偏易，保护信心） |
| ⑤模块权重 | 有理数运算30%/整式加减25%/一元一次方程应用25%/小学前置20% |
| ⑥解读侧重 | "能否适应初中节奏"/"计算习惯是否过关"/"应用题理解能力" |
| ⑦升学关联 | 中 |
| ⑧下探 | 下探至小学：分数四则混合运算、简易方程、基本几何量计算 |
| ⑨参照系 | 标准参照（MVP期），适应性三级评定+衔接缺口清单 |
| ⑩复测 | 8周后复测→指向S2期中适应诊断 |

## 1.4 推导规则A：定位类型 → 测量参数

| 参数 | 衔接诊断(S1/S3/S5) | 同步诊断(S2/S6) | 专题诊断(S4/S7) | 模拟诊断(S8) |
|---|---|---|---|---|
| 平均难度P | 0.70~0.75 | 0.65~0.70 | 0.55~0.65 | 对标真卷(约0.55~0.60) |
| 难度结构(易:中:难) | 6:3:1 | 5:3:2 | 4:4:2 | 复刻真卷结构 |
| 内容范围 | 本学期已学+下探一学段 | 本学期已学 | 单模块垂直深挖 | 全考纲 |
| Q矩阵 | 双层（前置+新授） | 单层 | 单层+垂直技能分解 | 单层 |
| 信度配对题 | 高频考点全配 | 高频考点全配 | 每个技能层级都配 | 核心模块配 |
| 结论产出 | 适应性评定+衔接缺口 | 掌握度清单+错因画像 | 模块能力分级 | 分数段预测+提分空间 |

专题诊断故意偏难：目的是把模块内能力层级切开（"卡在第几层"），中高档题不足则切不出层级。

## 1.5 推导规则B：诊断目标 → 元数据开关与结论产出

| 诊断目标 | 启用的元数据字段 | 结论产出物 |
|---|---|---|
| ①知识摸底 | 考点编码+掌握度判定 | 知识点红黄绿清单 |
| ②能力分级 | 认知层级+素养维度+难度 | 能力层级雷达图 |
| ③错因扫描 | 错因编码+诊断触发规则 | 错因分布画像 |
| ④升学衔接 | 前置知识链+依赖标注 | 衔接缺口+补课优先级 |
| ⑤专题突破 | 技能层级+垂直分解 | 层级定位+突破路径 |

开关式设计：未选目标对应的元数据字段一律不输出，避免分析师被无关字段淹没。

## 1.6 推导规则C：参照系两阶段策略

- **阶段一（0~300单）：标准参照**。结论形式为"掌握/不掌握""适应性达标/待加强"，锚点为定位卡预期均分与预设分数线。话术禁用"超过XX%同龄人"。
- **阶段二（300单以后）：常模参照**。同SKU同群体作答数据回流，计算百分位，报告升级"同龄百分位"模块——前期数据资产的自然变现与复购理由。
- **基础设施要求**：从第一单起，作答数据按"定位卡编码"分库存储；锚题跨批次复用，为常模等值提供链接题。

## 1.7 推导规则D：定位 → 报告话术与建议深度

| 定位 | 报告基调 | 建议深度 | 目标设定 |
|---|---|---|---|
| 衔接诊断 | 安抚+建立信心 | 浅：方法卡级 | 行为目标（"4周养成草稿分区习惯"） |
| 同步/专题 | 客观+具体 | 中：方法卡+变式训练 | 分数目标（"期中选择填空少丢6分"） |
| 模拟诊断 | 危机感+路径感 | 深：学习路径+应试策略 | 升学目标（具体高中/大学档位） |

## 2.2 编码体系（全产品线统一，禁止自创术语）

### 认知层级（安德森修订版布鲁姆分类）

L1 识记 / L2 理解 / L3 应用 / L4 分析与综合。命题结构要求 L3+L4 占比 ≥40%。

### 核心素养

- 初中（2022版课标，YS前缀）：YS-01抽象能力 / YS-02运算能力 / YS-03几何直观 / YS-04空间观念 / YS-05推理能力 / YS-06数据观念 / YS-07模型观念 / YS-08应用意识 / YS-09创新意识。每题限标1-2个主导素养。
- 高中（2017版课标，S前缀）：S1数学抽象 / S2逻辑推理 / S3数学建模 / S4直观想象 / S5数学运算 / S6数据分析。

### 错因编码量表（EC前缀，4大类16小类）

> 编码唯一性原则：错因一律EC前缀，与素养YS前缀严格区分，防止数据混淆。

| 大类 | 编码 | 名称 | 典型表现 |

## 2.3 Q矩阵与信度设计（认知诊断的根基）

1. **主考点唯一**：每题主考点唯一、关联考点≤1个——错误可归因的前提。
2. **信度配对题**：近5年考频≥3次的高频考点，每个配置≥2道不同题型/情境的测量题，互为配对。判定规则：配对两题全错→知识缺口（置信度高）；仅错一题→掌握不牢/偶发失误（置信度中，建议访谈确认）。
3. **禁止规则**：同一考点不得由3道及以上同质题重复考查（边际诊断信息递减，且挤占覆盖率）。
4. 配对题必须安排在**同一天施测模块内**（学生状态一致，比较才有效）。

## 2.4 三阶段命题流程（质量门禁）

**第一阶段：命题蓝图（双向细目表），禁止出题。** 输出蓝图后暂停，人工审核确认（重点核对：考点覆盖率≥90%、高频考点复测配额、难度比例）后方可进入下一阶段——蓝图是整卷质量的总开关。

**第二阶段：逐题命题，每批≤5题，逐题自验算。** 验算要求：代入答案回验、条件充分无矛盾、无非预期多解/无解。

**第三阶段：质量自检报告。** 覆盖率核对表、信度配对清单、内容效度（与近5年真题考点分布对齐率）、结构效度（层级与素养分布）、难度校验（全卷平均P落入定位卡基准区间）、公平性检查（无超纲/歧义/偏怪题）。

**信度口径（对外对内统一）**：诊断测验不使用全卷Cronbach's α（多维结构会人为拉低α，高α反而意味着冗余）。正确指标：①分模块α（目标0.75+）；②分类一致性（两次施测知识点掌握判定的一致率，MVP期用锚题组粗测）。

## 2.5 单题元数据规范（诊断字段，命题时强制填写）

```text
【题号】【题目】【题型/分值】
【标准答案】【评分细则】（解答题分步赋分，标注关键得分点与易丢分点，保证评分者一致性）
【完整解析】（至少一种通法，巧解附注）
【Q矩阵】主考点（编码+细分考点+教材章节）/ 关联考点（≤1个，无则填"无"）
【认知层级/主导素养】
【预估难度P/预估区分度】（P取0.30~0.90，区分度目标D≥0.3）
【预期作答时长】（秒；行为埋点的比对基准，必填）
【答案规范】（线上填空题必填：接受形式与容差，如"分数形式/小数容差±0.01/含π表达式"）
【干扰项设计说明】（选择题必填：每个错误选项分别由哪个EC编码产生，禁止凑数错项；
  正确选项不得因长度、位置、表述详略暴露）
【错因分析】（从EC量表选1~3个，逐一写出该错因在本题的典型错误过程示例）
【诊断触发规则】（if-then句式："若错误表现为X，则推断存在Y问题（置信度：高/中/低）"）
【改进建议】（1条可执行干预建议，具体到行为，禁止"加强练习"式空话）
【变式题】（1道，同考点同层级同错因映射、换情境数字，附答案；入库标记母题-变式关系）
```

解答题设计要求：设置2-3个小问，难度递进（入口宽、出口窄）；各小问独立得分，禁止"第(1)问不会则整题归零"的强依赖；线上版解答题拆为分步客观小问（见第四部分）。原创或深度改编，不得照搬真题原题（改编须改变情境、数据、设问中至少两项）。应用题优先河北本土情境（白洋淀、雄安新区、太行山旅游、唐山港等）。

## 2.6 高中学段专用模块（人教A版高三）

- **教材体系**：必修一（集合与逻辑/二次函数方程不等式/函数概念与性质/指数对数函数/三角函数）；必修二（平面向量与解三角形/复数/立体几何初步/统计/概率）；选必一（空间向量/直线和圆/圆锥曲线）；选必二（数列/导数及其应用）；选必三（计数原理/随机变量及其分布/成对数据统计分析）。
- **卷型锚定**：新课标I卷19题结构；命题前核对当年官方结构。
- **高频痛点矩阵**：函数与导数（含参讨论、恒成立）、三角（图象变换、边角互化）、数列（递推通项、求和、放缩）、立体几何（建系法向量）、解析几何（弦长面积最值、定点定值、韦达定理条件）、概率统计（分布列期望、条件概率与全概率）。
- **模块化诊断**：高三不做150分全真卷线上施测，六大模块独立成卷，每卷40-60分钟分次完成。
- **高三特有维度**：应试策略诊断（时间分配、取舍策略、压轴题第(1)问得分意识）。

# 第三部分 题库层

## 3.1 题库定位

建设的不是"试卷库"，而是**诊断探针库**——每道题都是带多维标定的测量工具，试卷只是题库按蓝图规则的一次抽样实例。题库质量 > 题库数量：200道全维度标定的题，远胜2000道只有答案解析的题。

## 3.2 题量配比（以单SKU为例）

| 用途 | 数量逻辑 | 七上衔接诊断示例 |
|---|---|---|
| 卷面题 | 3天×15-20题 | 45-60题 |
| A/B等值卷 | 卷面×2 | 90-120题 |
| 备用题 | 卷面×0.5 | 25-30题 |
| 报告变式训练题 | 与卷面同源（命题时同步产出） | 45-60题 |
| **题库总量** | **卷面×3~3.5倍** | **约160-200题** |

变式题全部入库并标记母题关系：既是报告"本周行动"的练习资源，又是复测时的平行题（避免记忆效应），也是二次探测的探测题。

## 3.3 题库元数据Schema

```text
# 诊断字段（命题时填写，见2.5）
考点编码 / 认知层级 / 素养维度 / 预估P值 / 预估区分度 / 错因映射(EC) /
预期作答时长 / 答案规范 / 信度配对编号 / 母题-变式关系 / 前置依赖标注

# 管理字段（题库运营时回填）
题目状态：候选 / 试测 / 在库 / 返修 / 退役
曝光次数（达上限自动暂停抽取）
实测P值 / 实测区分度（试测后回填）
干扰项有效率（每个错项被选比例，<5%为失效需改造）
所属SKU标签（可多选，一题跨SKU复用）
适用天次标签（Day1/Day2/Day3，可多选；题库按逻辑标签组织，不按物理目录）
锚题/平行组编号
版本号与终审人
```

## 3.4 平行题组与锚题库

**平行题组规范**：每个TOP20高频痛点考点准备3-5道平行题——同考点、同认知层级、同错因映射、难度差<0.05，情境与数字全换。四大用途：①复测平行卷（防记忆效应）；②A/B等值卷；③二次探测题；④等值后测卷题源。

**锚题库（独立子库，永不进入普通抽题池）**：跨天校准锚题≥20道（按TOP考点分4组平行题组）。三大用途：①跨天等值链接；②跨人/跨批次校准（常模建设基础）；③质量监控（锚题区分度下降=泄题或群体变化，触发更换）。

**锚题使用纪律**：锚题只换数字情境、不附带任何反馈讲解（防止锚题本身成为教学材料制造练习效应）；锚题表现差异用于报告**信度标注**（"该模块能力估计可能受练习效应影响，建议复测确认"），不用于个体能力的系数修正（2-3道锚题样本量不足，修正会引入更大误差）。

## 3.5 组卷引擎（蓝皮书配置化）

- **蓝皮书（exam_blueprint表）**：定位卡+双向细目表的结构化存储，组卷引擎读表执行——实现"换SKU=换定位卡"的技术落地。
- **组卷约束**：①每天模块包内平均难度差≤0.05、认知层级分布一致（跨天等值）；②信度配对题同日出现；③同一学生A/B卷随机分配，复测用另一套；④单题曝光上限控制。
- **两种组卷模式**：标准组卷（严格按蓝皮书比例，用于诊断卷与后测卷）；薄弱点组卷（学生画像中掌握度<40%的考点出题权重×2，用于干预包与日常练习）。

## 3.6 校准机制与题目状态机

**统计标定三阶段**（学术级模型让位于数据量）：

| 阶段 | 样本量 | 方法 | 标定内容 |
|---|---|---|---|
| MVP试做 | 30-50人 | 经典测量理论(CTT) | 难度P、区分度D、干扰项有效率 |
| 种子期积累 | 100-300人 | CTT精细化 | 题目健康度、锚题稳定性 |
| 规模化 | 500+人/批次 | IRT（先Rasch/1PL，再上3PL） | a/b/c参数，激活CAT接口 |

**处置规则**：实测P与预估偏差>0.15→复核（题干歧义/答案错误）；区分度D<0.2→退役改造；干扰项失效→改造。

**状态机**：候选（命题完成）→ 试测（Phase3达标）→ 在库（可抽题）→ 退役（区分度衰减/泄题）；不达标进返修池。

**待校准参数制度**：所有经验初始值（计分权重、0.4时间阈值、20%提升率阈值等）统一标记"待校准"，前200单真实数据回流后反向校准，作为Phase 5健康度审查的固定议程。

## 3.7 题库建设路径（Phase 0-5）

| 阶段 | 动作 | 题量目标 | 耗时 |
|---|---|---|---|
| Phase 0 标定基座 | 冀教版2024目录核对定稿；考点编码表；前置依赖关系表；EC量表冻结；题库schema冻结 | — | 3天 |

# 第四部分 施测层：H5三天诊断

## 4.1 三天认知递进模块设计（核心施测形态）

按认知层级递进分天，而非按内容分天——同一知识点在三天内被不同层级题目垂直穿透，实现错因交叉验证（"有理数运算Day1选择错→Day2填空错→Day3解答还错"才能高置信度判定概念性薄弱）：

| 天次 | 定位 | 时长/题量 | 内容设计 | 即时反馈 |
|---|---|---|---|---|
| Day 1 | 基础能力扫描（L1-L2） | 30分钟/20题 | 选择为主，快速定位知识盲区；含2-3道锚题 | 5分钟内出"参与质量反馈"（见4.3反馈规则） |
| Day 2 | 应用能力诊断（L2-L3） | 35分钟/18题 | 填空+中档分步解答，概念精准度与方法选择；含锚题校准组 | 模块点亮进度 |
| Day 3 | 综合与思维诊断（L3-L4） | 40分钟/15题 | 压轴分步解答+新情境应用，深度推理诊断 | 完整报告生成 |

总题量53题、总时长105分钟分3次。每天严格限时、超时强制交卷；支持7天窗口期内完成（断点续答），Day2/Day3开启时推送提醒；未完成三天者给"部分诊断简报"并明确标注"基于不完整数据"。

## 4.2 四大风险对策

| 风险 | 对策 |
|---|---|
| 练习效应 | 锚题跨天校准（仅做信度标注）；锚题不带反馈；三天内容不重复教学 |
| 间隔效应 | 7天完成窗口收窄变异；报告记录各天间隔天数供分析师参考 |
| 动机衰减 | 难度严格递增（Day1偏易保护信心）；中性进度反馈；社会认同提示（"已有XX位同学完成3天诊断"） |
| 环境变异 | 首屏建议安静环境一次性完成当日模块；切屏/中断事件埋点记录，异常答卷进可信度校验 |

## 4.3 试卷结构与交互规范

**每日结构**：热身题2道（超基础，不计分）→ 正式题 → 当日反馈。

**低信度答卷判定（多信号联合，三取二）**：热身题答错 且 全卷平均作答时长<预期50% 且 修改率异常——满足任意两项标记"低信度答卷"，报告进人工复核。禁止单一信号判定。

**题型与交互**：
- 选择题：单选点选，可修改，记录选项切换次数与路径；答错选项即错因证据（干扰项-EC映射）。
- 填空题：答案为整数/最简分数时数字键盘；含符号时提供快捷栏（π、√、°）；判卷严格按题目级【答案规范】字段执行，禁止全局"智能等价识别"。
- 解答题：拆为2-3个分步输入框逐框作答（每框独立赋分、独立归因），保留"过程分暴露点"；支持"文字描述思路+拍照上传草稿"双模式。
- 作答控制：一屏一题；**允许回翻但只读禁改**（兼顾数据独立性与回翻行为采集）；首屏含过程数据告知语；每模块结束设"我不会/蒙的"主动标记统计。

**反馈规则（动机保护红线）**：测试过程中禁止任何形式的能力/得分反馈（得分率、对错、雷达图预览均禁止）——中途暴露表现会改变后续作答行为、污染数据并诱发弃测。只允许：完成度进度、参与质量反馈（"答题专注度超过XX%的参与者"）、模块点亮图标。

**设备适配**：手机端优先，一屏一题，字体≥16px，公式MathJax渲染，图形题配图须移动端清晰且关键条件图文双标注，禁止左右滑动。MVP期不开发交互题（拖拽/动态几何）。

## 4.4 行为埋点体系

| 埋点类型 | 具体字段 | 优先级 |
|---|---|---|
| 时间数据 | 每题停留时长、首次点击到提交间隔、修改间隔 | P0 |
| 操作轨迹 | 选项切换次数与路径(A→B→A)、填空修改记录、**删除重写次数** | P0 |
| 放弃行为 | 跳过、空白、最后几秒随机选、"我不会/蒙的"主动标记 | P1 |
| 辅助行为 | 草稿拍照次数、回翻次数（只读） | P1 |
| 分段数据 | 同日内的前半vs后半正确率与速度变化（疲劳检测仅限日内比较，禁止跨天比较——Day3更难与疲劳无法区分） | P1 |
| 设备/环境 | 设备类型、切屏次数、中断事件 | P2 |
| 自信度评分 | 1-5分，每模块结束后对3道关键题回溯评分（支撑元认知维度；字段预留，MVP可暂缓） | P2 |

**技术规范**：批量压缩上报（每10秒或切题时），禁止逐条POST；中断后可从断点继续。

## 4.5 二次探测引擎（防蒙猜，融合自算法架构文件）

```text
IF 作答耗时 < 该题预期作答时长 × 0.4 AND 答对：
    标记"低置信度正确"
    自动补推1道同考点平行题（同难度，难度差<0.05，换情境——调用平行题组）
    IF 平行题答错：
        原题改判"疑似蒙对"，不计入掌握度
        标记 behavior_tag = "猜测倾向"
```

阈值0.4标记"待校准"。注意：补推题必须是同难度平行题，禁止"难度+1"（蒙对者做更难题必错，验证失去意义）。

## 4.6 行为→错因推断规则集（自动预推荐，分析师确认）

| 行为模式 | 推荐EC编码 | 置信度 |
|---|---|---|
| 时长>预期2倍 且答错 | EC-K类（知识缺口，卡壳硬耗） | 高 |
| 时长<预期1/3 且答错 | EC-N2/EC-C1（粗心/审题） | 中 |
| 选项切换≥2次 且最终答错 | EC-K类（知识不扎实，犹豫型） | 中 |
| 选项切换≥2次 且最终答对 | 掌握不牢，需巩固（"伪掌握"标记） | 中 |
| 分步解答第n步错（前步对） | EC-M2（程序断点，定位到步） | 高 |
| 删除重写≥3次 且最终答对 | EC-M2（步骤跳脱/执行功能弱，加重权重） | 高 |
| 犹豫标记 且答错 | EC-C1（审题漏看） | 中 |
| 多题集中放弃 | EC-N3（畏难/时间策略） | 中 |

使用原则：行为数据永远与作答对错联合判定，不单独下结论；推断阈值来自题库"预期作答时长"字段；草稿拍照次数等弱证据仅供分析师参考，不进自动规则。

# 第五部分 报告生成层

## 5.1 四层管线架构

```text
生产层1：预制库（人工审核入库，版本化管理）
  → 错因-方法映射表（方法卡，含适用边界+验证指标）
  → 知识点-前置依赖表
  → 典型薄弱组合处方
  → 报告模板（含常模缺失时的降级文案）
        ↓
生产层2：规则组装引擎（确定性算法，零AI）
  → 置信度判定（信度配对题交叉验证）
  → 路径定序（前置依赖链拓扑排序）
  → 追根溯源（沿依赖链下探定位根源节点）
  → 4周计划组装（方法卡×薄弱点×依赖链）
  → 数据可信度校验（时长/空白率/猜测率/低信度答卷）
        ↓
生产层3：AI叙述层（只表达，不决策）
  → 输入：组装层的结构化结论（非原始答题卡）
  → 输出：个性化段落（200-300字）
        ↓
质检门禁：分析师人工复核（分析师工作台）
  → MVP期（前300单）：100%全量复核
  → 稳定期：异常值+投诉+低置信度报告+5%抽检
  → 每处人工修改回流为方法卡/规则迭代数据
```

AI输入限定为结构化结论的理由：直接喂原始答题卡，AI既要算又要写，错误率叠加；喂结构化结论，AI只做语言转化，幻觉空间最小。

## 5.2 预制库规范

**方法卡字段（四列必填）**：

| 字段 | 说明 | 示例（EC-M1运算失误） |
|---|---|---|
| 错因编码 | EC-16之一 | EC-M1 |
| 预制方法 | 具体干预技术 | "慢算训练法"：每天10分钟，强制书写每一步，禁用口算 |
| 适用边界/禁忌 | 防止方法错配 | 不适用于答题时间严重不足者（先用"草稿分区法"） |
| 验证指标 | 供效果回流判定 | 4周后复测，运算类错因占比降至15%以下视为有效 |

**入库审核规范（Step 0）**：审核人资质（一线教师/教研）、审核标准（干预手段与错因有文献或实践经验依据）、版本号管理。

**典型方法卡样例**：

| 错因 | 方法 | 4周路径 |
|---|---|---|
| EC-K1概念模糊 | "概念溯源法"：回到教材定义，自己的话复述+3个正例+1个反例 | W1精读定义→W2概念辨析→W3变式判断→W4综合应用 |
| EC-M3模型识别失败 | "模型卡片法"：条件特征→模型名称→解题套路对应表 | W1整理5个核心模型→W2识别专项→W3变式→W4混合实战 |
| EC-M1运算失误 | "慢算训练法" | W1整式慢算→W2方程慢算→W3限时准算→W4综合运算 |

## 5.3 规则组装引擎

**路径定序**：诊断为多个知识缺口时，查询前置依赖表做拓扑排序（先补前置缺口再补当前考点），输出4周有序计划。教育决策由确定性算法执行，AI不得参与定序。

**追根溯源算法**（融合自算法架构文件）：

```text
错题关联考点K → 查询依赖表中K的全部前置链
→ 沿链检查学生历史掌握度
→ 定位"掌握度<50%的最深层节点" = 根源性薄弱点
→ 4周计划从根源节点开始编排，而非从当前错题开始
```

**置信度判定前置**：低置信度错因（配对题一错一对）不进入"首要错因"位置；报告对应结论降级并标注"建议访谈确认"。

**数据可信度前置**：作答时长远低于预期、空白率>30%、自标"蒙的">20%→先输出"本次数据可信度有限"降级提示，不生成看似精密的分析。

## 5.4 AI叙述层触发规则（操作化定义）

满足任一条件时生成个性化段落（200-300字）：

1. 一级错因分类≥3类（按EC-K/M/C/N大类计数，防同一大类内二级错因凑数）；
2. 跨课标领域错误（数与代数/图形与几何/统计与概率/综合与实践，领域清单预定义）；
3. 思维性错因（EC-C类）占**已归因错题数**>30%（分母剔除空白题与自标"蒙的"题）。

## 5.5 质检门禁：分析师工作台（融合自算法架构文件）

- 界面：左侧待复核学生列表，右侧作答数据+系统基于4.6规则集**预推荐的EC编码**；
- 操作：分析师只需"确认/修改"推荐编码与报告内容，**单题处理≤3次点击**；
- 每处修改自动记录，回流为规则集与方法卡的校准数据；
- 全量复核退为抽样的条件：连续100份报告平均每份人工改动<2处后，切换为"异常值+投诉+低置信度+5%随机抽检"。

# 第六部分 诊断-干预-验证闭环层（L3，融合自算法架构文件）

## 6.1 触发条件

某根因维度高概率（或报告某维度得分<35/100）且**经分析师手动确认**后触发。MVP期禁止系统自动推送干预包——教育决策不由算法单独做。

## 6.2 干预包规范（3天极简包）

- 每日推送5-8题，全部聚焦单一根因维度；每日≤10分钟；
- 内容逻辑：Day1基础巩固→Day2变式训练→Day3综合应用（调用方法卡4周路径压缩版+薄弱点组卷）；
- 每日附一条"30秒策略提示"（非单纯答案）。

## 6.3 等值后测与三区判决

第4天推送等值后测卷：从**平行题组**抽取，难度分布与考点覆盖与前测严格等值；每个根因维度题量≥5题（个体层面判决的最低样本量）。

```text
IF 后测正确率 - 前测正确率 >= 20%：锁定根因，诊断成立，结案
IF 介于 10%-20%：部分成立，延长干预2天再测，或标记"教研待复核"
IF < 10%：推翻假设，重置该维度判定，回退重新搜索（进分析师复核队列）
```

阈值20%标记"待校准"。判决结果与所用方法卡关联存储——这是方法卡"验证指标"字段的执行引擎：某方法卡多次关联"推翻假设"，回炉修订；持续关联"锁定根因"，权重上调。**这一步使产品从"服务"进化为"可迭代的数据资产"。**
