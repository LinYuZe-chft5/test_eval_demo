## 【D3-01】（2分）

**【题目】** 规定：数轴上点P表示的数为$x$，若$|x+1|=3$，则称点P为“基准点”。满足条件的“基准点”表示的数是（ ）
- A. $2$
- B. $-4$
- C. $2$或$-4$
- D. $4$或$-2$

**【题型/分值】** 选择 / 2分
**【标准答案】** C
**【评分细则】** 选对得2分，选错或不选得0分。
**【完整解析】** |x+1|=3，则x+1=3或x+1=-3，解得x=2或x=-4。两种情况都要考虑。故选C。
**【Q矩阵】** 主考点：KP-01.2 / 关联考点：KP-01.3
**【认知层级/主导素养】** L3 / YS-03
**【预估难度P/区分度目标】** P=0.65 / D≥0.3
**【预期作答时长】** 90秒
**【干扰项设计说明】**
- A（EC-C3）：只求出x+1=3一种情况，分类不完整
- B（EC-C3）：只求出x+1=-3一种情况，分类不完整
- D（EC-M1）：移项符号错误
**【错因分析】**
1. EC-C3：选A或B，绝对值方程只考虑一种情况——分类讨论意识缺失（本题核心探测点，七上思维层级分水岭）。
2. EC-M1：选D，x+1=±3移项时符号出错。
**【诊断触发规则】** 若选A或B，判定“绝对值双解”分类意识缺失，标记L3层级天花板，该生在后续含参讨论题上将持续受限（置信度：高）；若与D1-04（|a|=7填±7者）联动，可区分“不会分类”与“会分类但不耐烦”两种画像（置信度：中）。
**【改进建议】** 绝对值方程“一拆二”口诀：看见|式子|=正数，立刻写成“式子=正”和“式子=负”两行再分别解；练5道，每题必须写出两行。
**【变式题】** 若$|y-2|=5$，则$y=$（ ）A. $7$ B. $-3$ C. $7$或$-3$ D. $3$或$-7$
**【变式答案】** C

**【题目】** 用火柴棒按下图规律摆正方形：摆1个正方形用4根，摆2个相连的正方形用7根，摆3个相连的正方形用10根……按此规律，摆$n$个相连的正方形需要火柴棒____根（用含$n$的式子表示）。

**【标准答案】** 3n+1
**【评分细则】** 填3n+1（或4+3(n-1)等等价形式）得2分；其余得0分。
**【完整解析】** 每增加1个正方形增加3根火柴棒（共享一条边）。首项4根，公差3：4+3(n-1)=3n+1。检验：n=3时3×3+1=10 ✓。
**【Q矩阵】** 主考点：KP-03.3 / 关联考点：KP-03.2
**【认知层级/主导素养】** L4 / YS-05,YS-09
**【预估难度P/区分度目标】** P=0.5 / D≥0.3
**【预期作答时长】** 150秒
**【答案规范】** 接受形式：expression
**【错因分析】**
1. EC-C3：答4n，忽略相邻正方形共享边，把局部规律当整体——以偏概全（本题核心探测点）。
2. EC-M3：能看出“每次多3”但组织不成式子，答3n（漏首项修正），模型构建半成品。

**【诊断触发规则】** 若答3n，判定“变化率抓取成功、初始量锚定失败”，与D2-06（表格关系式选C）联动——两处同中则建模双要素缺陷成立（置信度：高）；若答4n，判定归纳推理停留在表面计数，L4层级未达标（置信度：高）。
**【改进建议】** 规律题“三步归纳”：①写出前3项的具体数②算相邻差确定“每次变多少”③用第1项反推修正项（4=3×1+1），再用第2、3项检验；练4组图形规律。

## 【D3-04】（2分）

**【题目】** 一个长方形的长是宽的2倍，周长是36cm，它的面积是____cm²。

**【题型/分值】** 填空 / 2分
**【标准答案】** 72
**【评分细则】** 填72得2分；其余得0分。
**【完整解析】** 设宽为x cm，则长为2x cm。周长：2(x+2x)=36，6x=36，x=6；长12cm；面积12×6=72cm²。
**【Q矩阵】** 主考点：KP-P.3 / 关联考点：KP-05.3
**【认知层级/主导素养】** L3 / YS-03
**【预估难度P/区分度目标】** P=0.68 / D≥0.3
**【预期作答时长】** 120秒
**【答案规范】** 接受形式：integer
**【错因分析】**
1. EC-C4：求出宽6或长12就停笔，忘求面积——多步问题目标丢失（与D3-03选A同一模式，跨天验证）。
2. EC-K1：周长公式用错（忘乘2），x+2x=36得x=12，面积288——公式记忆缺口。
3. EC-M1：6×12口算出错。
**【诊断触发规则】** 若用算术法（36÷6=6）自然完成，说明小学几何功底扎实，前置层达标（置信度：高）；若周长公式都错，判定小学几何前置缺口，标记KP-P.3为衔接缺口（置信度：高）；若与D3-03同现“求出中间量即停笔”，行为模式锁定，报告单列“目标保持”训练建议（置信度：高）。
**【改进建议】** 多步应用题在草稿纸顶端先写“最终求什么”（面积=长×宽=?），每求出一个中间量就打勾确认“这是中间量，还不是答案”。
**【变式题】** 一个长方形的长比宽多4cm，周长是28cm，面积是____cm²。
**【变式答案】** 45（设宽x：2(x+x+4)=28→x=5，长9，面积9×5=45）

**【题目】** 一个长方形的长为$(2a+3)$cm，宽比长少$a$ cm，则这个长方形的周长用含$a$的式子表示为（ ）

- D（EC-M1）：合并同类项出错
**【错因分析】**

2. EC-K2：-ab项符号处理错，4-6=-2。
