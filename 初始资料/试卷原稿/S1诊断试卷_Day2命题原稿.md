## 【D2-01】（2分）

**【题目】** 计算：$-\frac{1}{2}+\frac{3}{4}-(-\frac{1}{4})=$____。

**【题型/分值】** 填空 / 2分
**【标准答案】** 1/2
**【评分细则】** 填1/2（或0.5、2/4）得2分；结果不约分不扣分，但符号错不得分。
**【完整解析】** 原式=-1/2+3/4+1/4（减去负数变加正数）=-2/4+3/4+1/4=2/4=1/2。
**【Q矩阵】** 主考点：KP-P.1 / 关联考点：KP-01.7
**【认知层级/主导素养】** L2 / YS-02
**【预估难度P/区分度目标】** P=0.72 / D≥0.3
**【预期作答时长】** 100秒
**【答案规范】** 接受形式：fraction
**【错因分析】**
1. EC-K2：-(-1/4)未变号，算成-1/2+3/4-1/4=0——减法符号转换在分数混合中失守。
2. EC-M1：通分后分子运算出错。
3. EC-C1：漏做第三项，得1/4。
**【诊断触发规则】** 若本题错且D1-06、D1-12（均关联KP-P.1）也错，三层证据链闭合，追根溯源锁定分数运算前置缺口为有理数模块的病根（置信度：高）；若仅本题错，倾向多步程序保持问题（置信度：中）。
**【改进建议】** 分数加减混合统一用“先通分、再合并、最后约分”三步流程，每步一行；特别练含“-(-分数)”结构的题5道。
**【变式题】** 计算：$-\frac{1}{3}+\frac{5}{6}-(-\frac{1}{6})=$____。
**【变式答案】** 2/3

## 【D2-02】（2分）

**【题目】** 数轴上点A表示的数是$-3$，点B表示的数是$2$，则A、B两点间的距离是（ ）
- A. $1$
- B. $5$
- C. $-5$
- D. $6$

**【题型/分值】** 选择 / 2分
**【标准答案】** B
**【评分细则】** 选对得2分，选错或不选得0分。
**【完整解析】** 数轴上两点间的距离等于两数之差的绝对值：|2-(-3)|=|2+3|=5。也可以数格子：从-3到0是3个单位，从0到2是2个单位，共5个单位。故选B。
**【Q矩阵】** 主考点：KP-01.2 / 关联考点：KP-01.3
**【认知层级/主导素养】** L3 / YS-03
**【预估难度P/区分度目标】** P=0.65 / D≥0.3
**【预期作答时长】** 60秒
**【干扰项设计说明】**
- A（EC-C2）：直接做(-3)+2=-1再取绝对值，把距离当成代数和
- C（EC-K1）：距离出现负值，概念性错误
- D（EC-M1）：2-(-3)计算出错
**【错因分析】**
1. EC-C2：把“距离”当“和”处理，(-3)+2=-1得1——几何量与代数运算表征混淆（本题核心探测点）。
2. EC-K1：答-5，不理解距离是非负量。
3. EC-M1：2-(-3)减法出错得6或其他。
**【诊断触发规则】** 若选A，则标记“数轴几何意义→代数运算”转换通道不畅，该生在后续绝对值几何意义、数形结合题上高风险，联动D3-01复核（置信度：中）；若选C，判定距离概念未建立（置信度：高）。
**【改进建议】** 画数轴数格子：做5道异号两点距离题，先画图标出两点、数出格子数，再用|a-b|公式核对，两种方法结果必须一致才算完成。
**【变式题】** 数轴上点M表示$-1$，点N表示$4$，M、N两点间的距离是（ ）A. $3$ B. $5$ C. $-5$ D. $4$
**【变式答案】** B

## 【D2-03】（2分）

**【题目】** 计算：$\frac{5}{6}\times(-\frac{3}{10})+\frac{1}{4}=$____。

**【题型/分值】** 填空 / 2分
**【标准答案】** 0
**【评分细则】** 填0得2分；其余得0分。
**【完整解析】** 先算乘法：5/6×(-3/10)=-15/60=-1/4（异号得负）；再算加法：-1/4+1/4=0。
**【Q矩阵】** 主考点：KP-P.1 / 关联考点：KP-01.8
**【认知层级/主导素养】** L3 / YS-02
**【预估难度P/区分度目标】** P=0.7 / D≥0.3
**【预期作答时长】** 120秒
**【答案规范】** 接受形式：integer
**【错因分析】**
1. EC-K2：乘法丢负号，算成1/4+1/4=1/2——符号法则在乘法-加法混合链中丢失。
2. EC-M1：分数乘法约分出错（5/6×3/10错算成1/2等），得3/4、-1/2等。
3. EC-M2：先加后乘，运算顺序错误，得5/24等。
**【诊断触发规则】** 若答1/2，判定符号保持为多步运算薄弱环节，与D1-12、D2-01合并归因为同一程序性缺陷，干预不分三条线（置信度：高）；若运算顺序错（先加后乘），属法则性错误需重新讲授（置信度：高）。
**【改进建议】** 混合运算“先圈乘除、再算加减”：动笔前用铅笔把乘法部分圈出来先算；做6道“分数乘法+加减”混合题，每题第一步必须是乘法。
**【变式题】** 计算：$\frac{3}{4}\times(-\frac{2}{9})+\frac{1}{6}=$____。
**【变式答案】** 0

## 【D2-06】（2分）

**【题目】** 一辆货车从石家庄运送货物到白洋淀，下表记录了行驶时间$x$（小时）与油箱剩余油量$y$（升）的部分数据：$x=0$时$y=45$；$x=1$时$y=39$；$x=2$时$y=33$；$x=3$时$y=27$。则$y$与$x$之间的关系式是（ ）

- B. $y=45+6x$
- C. $y=6x$
- D. $y=45-4x$

**【题型/分值】** 选择 / 2分
**【标准答案】** A
**【评分细则】** 选对得2分，选错或不选得0分。
**【完整解析】** 每过1小时油量减少45-39=6升，初始油量为45升，所以y=45-6x。检验：x=3时y=45-18=27 ✓。故选A。
**【Q矩阵】** 主考点：KP-03.3 / 关联考点：KP-03.2
**【认知层级/主导素养】** L3 / YS-01
**【预估难度P/区分度目标】** P=0.68 / D≥0.3
**【预期作答时长】** 90秒
**【干扰项设计说明】**
- B（EC-C1）：油量应减少却写成增加，变化方向读反
- C（EC-M3）：只看到每小时6升的变化量，漏掉初始油量45
- D（EC-M1）：变化率读错，45-39=6误算为4
**【错因分析】**
1. EC-M3：只抓住变化率6、漏掉初始量45，选C——从表格提取“初始量+变化率”双要素的建模意识缺失（本题核心探测点）。
2. EC-C1：增减方向读反，选B。
3. EC-M1：变化率算错，选D。
**【诊断触发规则】** 若选C，判定“从数据到关系式”的建模双要素意识缺失，该生在Day3规律探究题（D3-02）与方程应用列式（D3-07/08）上高风险（置信度：中）；若选B或D，属读表精细度问题（置信度：中）。
**【改进建议】** 读表建模“两句口诀”：先问“开头是多少”（初始量），再问“每次变多少”（变化率），两句话合成一个式子；用3组表格数据练写关系式并回代一组数据检验。
**【变式题】** 某停车场收费标准如下表：停车$x$小时收费$y$元：$x=1$时$y=5$；$x=2$时$y=8$；$x=3$时$y=11$。则关系式是（ ）A. $y=3x$ B. $y=3x+2$ C. $y=5x$ D. $y=2x+3$
**【变式答案】** B

## 【D2-10】（2分）

**【题目】** 下列方程中，是一元一次方程的是（ ）
- A. $x^2-3x=0$
- B. $2x+1=7$
- C. $x+y=5$
- D. $\frac{1}{x}=2$

**【题型/分值】** 选择 / 2分
**【标准答案】** B
**【评分细则】** 选对得2分，选错或不选得0分。
